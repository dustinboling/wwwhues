# Gap Audit — Security, Privacy, Reliability, Operations

Auditor: security/reliability specialist seat. Date: 2026-11-22.
For: Hue. Method: profession's best practice first (OWASP, Cloudflare,
GitHub official docs — all read 2026-11-22), then Dustin's house
standards. Every file in this folder was read in full or grepped
end-to-end for this cluster's vocabulary (CSP, CSRF, rate limit,
Turnstile, monitor, backup, rollback, retention, analytics, lint,
typecheck…): the near-total absence of hits *is* the finding.

**Overall verdict:** the spec is strong on what the sites will look
like and how they will be found, and nearly silent on how they will
be *defended, watched, and recovered*. The words "secure" appear once
in the entire build brief — as an adjective in non-negotiable 9
("performant, secure"), with no control named anywhere to make it
true. Quinn gates design, not code (brief, line 7), so unless these
amendments land in the spec, no seat in the program owns them and
they will not happen by accident.

Evidence grades: **STRONG** = an official source read today states
the practice directly. **MODERATE** = official sources verify the
components; the assembled practice is industry consensus.
**WEAK-CONTENDED** = none claimed in this audit.

## What the spec already gets right (for the record — not credited above)

- **META_API_KEY handling** (brief, line 6): named, in Secrets, never in chat or memory — the one secret practice the spec states, and the model gap 9 extends.
- **Migration rollback posture** (Bea §5.3): a pre-agreed rollback trigger (indexed-page drop > 10% or a canonical leaving the index) and the old stack kept deployable until day-28 sign-off, per property. Gap 7 extends this from the migration to ordinary releases; it does not replace it.
- **Quinn's raw-HTML JS-disabled test** (brief NN3): a real acceptance test with teeth — the pattern gaps 3 and 10 ask to be added to.
- **Offline caching scoped to public facts** (Nadia §5): the shell caches hours/directions/policies and queues transactions rather than failing — the right instinct; gap 13 adds the missing negative rule.
- **httpOnly named for sessions** (brief NN5): one correct flag, specified. Gaps 2 and 12 complete the contract around it.

## Top 5 (for Hue)

1. **Security headers + CSP (gap 1, Critical)** — absent entirely; two serving paths (static `_headers` vs Worker code) mean it must be specified or it lands on half the site.
2. **CSRF posture (gap 2, Critical)** — every mutation rides ambient cookies, including a parent-domain SSO cookie spanning six game subdomains; OWASP: SameSite alone is not the control.
3. **Turnstile + rate limiting (gap 3, Critical)** — every public write endpoint is unprotected, including the game votes that feed the December 1 wholesale order.
4. **R2 media bucket protection (gap 4, Critical)** — R2 has no versioning; tonight's move makes one bucket the only served copy of irreplaceable artwork. Bucket locks + an independent copy + a restore drill.
5. **Error monitoring & alerting (gap 5, Important)** — nothing watches six properties break; Cloudflare's native Workers Logs + Issues make this configuration, not procurement — if the spec asks.
